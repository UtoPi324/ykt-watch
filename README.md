# ykt-watch

雨课堂（长江雨课堂）课堂习题监听 + 自动作答。纯 Python 标准库。

## 使用方法

1. `config.json` 里填 cookie 和 AI 的 key。
2. 打开 edge，搜索长江雨课堂或雨课堂网页版，进入，扫码登录。
3. 登录后 f12，打开网络栏，找到 index，点击，在右侧可以看到标头，在请求标头中找到 cookie，
   在 cookie 中找到 sessionid，完整复制 `sessionid=...` 到 `config.json` 的 cookie 里。
4. 在脚本目录下右键，在终端中打开，输入 `py ykt` 按 tab 自动补完，enter 运行。

```
python ykt_watch.py            # 自动答题
python ykt_watch.py --detect   # 只检测不提交，确认链路
python ykt_watch.py --check    # 自检：配置 ， 连一次 WS 就退
```

## 注意

1. 不同雨课堂（如长江雨课堂）服务器不互通，先确认老师用的是哪个。
2. 需要电脑已装 python，怎么装自己百度。
3. 脚本会自动识别当前正在上的课程并进入。需要在教室签到的课，可以先在电脑上启动脚本，
   再去教室签到然后跑路；签到成功后脚本会自动进入课堂并待机做题。
4. 注意不要泄露自己的 sessionid 和 api key。可以接别的平台的 openai 格式 api，但模型必须有视觉。
5. 正常情况 sessionid 填一次就不变了，直接运行脚本就能自动识别现在的课。但是千万不要再次在网页端
   扫码登录雨课堂，每次扫码后 sessionid 都会变，此时需要复制新的；同理哪天突然不能用了就重新登录换新的。
6. 一个目录只跑一个进程。启动会写 `watch.lock`（内容是 PID），正常退出自动删掉；
   如果误开两个，第二个会拒绝启动，避免同一道题互相抢答。
7. 课结束时服务端会回 `lesson finished` 并不再应答心跳，脚本会自己识别、待机、必要时重连，属正常现象。
   卡住或反复重连时看 `logs/events.jsonl`，里面有收发记录和异常栈。
8. 以上用到的全部是 python 标准库，不需要额外安装。
